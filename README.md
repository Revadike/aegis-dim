# DIM Aegis Overlay


[![GitHub stars](https://img.shields.io/github/stars/Revadike/aegis-dim?style=flat-square)](https://github.com/Revadike/aegis-dim/stargazers) [![Version](https://img.shields.io/badge/version-1.2.2-blue?style=flat-square)](https://github.com/Revadike/aegis-dim) [![Tampermonkey compatible](https://img.shields.io/badge/Tampermonkey-compatible-orange?style=flat-square)](https://www.tampermonkey.net/) [![License: MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square)](LICENSE)

A lightweight userscript that overlays Aegis weapon tier list analysis onto Destiny Item Manager item popups.

## Features

- Overlays tier and rank badges on weapon popups.
- Shows Aegis recommended perks and mag/barrel suggestions.
- Displays Aegis analysis notes for quick context.
- Suggests best-in-category weapons by energy type and frame.
- Caches spreadsheet data locally for faster lookups.

## Quick install

1. Install [Tampermonkey](https://www.tampermonkey.net/)
2. Install the [userscript](https://github.com/Revadike/aegis-dim/raw/refs/heads/master/dim-aegis.user.js)
3. Open [Destiny Item Manager](https://app.destinyitemmanager.com/) and view an item popup to see the overlay
